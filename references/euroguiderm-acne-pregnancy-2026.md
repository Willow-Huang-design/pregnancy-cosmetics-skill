## L3 跨章节聚合

### 收敛结论

- 孕期痤疮外用选择有限时，壬二酸和 BPO 是本指南明确列出的可考虑选项。[来源：Table 4；PDF P.7]
- 系统性异维A酸在孕期和备孕期为强禁忌，证据方向与现有 Skill 的避免导向一致。[来源：Treatment during pregnancy；PDF P.7]

### 细化条件

- `strong consensus / 100% agreement` 描述专家组对推荐的共识程度；具体行动措辞仍是 `can be considered`，不能翻译成“强烈推荐使用”。[来源：Table 1、Table 4；PDF P.2、7]
- BPO 的一般癌症安全背景来自痤疮患者研究，不构成孕期致畸风险的直接量化。[来源：BPO safety；PDF P.4-5]
- 外用抗生素属于治疗性药物，需考虑耐药和处方管理，不能作为普通护肤品自由推荐。[来源：Treatment during pregnancy；PDF P.7]

### 缺失与不可外推

- 没有哺乳期建议。
- 没有孕周分层、浓度阈值、使用面积和频率规则。
- 没有将 Retinol、Retinal 等化妆品维A衍生物逐项分类。
- 没有对全部护肤和彩妆进行评价。

## L4 决策结构

1. 用户因孕期痤疮询问壬二酸或 BPO
   → 核对完整 INCI、是否外用、浓度、面积、频率、驻留/淋洗和是否为药品
   → 可引用本指南表述为“可以考虑”
   → 若高浓度、大面积、皮肤破损、联合治疗或症状严重，转产科/皮肤科评估。

2. 用户询问外用克林霉素或红霉素
   → 识别为治疗性抗生素
   → 不提供剂量
   → 说明指南在有限条件下允许考虑，同时提示耐药和医疗管理。

3. 用户询问口服/系统性异维A酸，且正在备孕或怀孕
   → 输出“指南明确强禁忌”
   → 不讨论自行减量或停药算法
   → 建议尽快联系开药医生、产科医生或药师。

4. 用户询问 Retinol、Retinal、Tretinoin、Adapalene 等其他类维A成分
   → 不把系统性异维A酸结论机械复制
   → 回到数据库和其他成分专门来源
   → 无直接条目时标记证据缺口并生成待补录条目。

## L5 可调用模块

### 孕期痤疮外用成分核对

- **输入**：孕周、完整 INCI、产品是药品还是化妆品、浓度、面积、频率、驻留/淋洗、是否联合其他祛痘药。
- **直接命中**：Azelaic Acid、Benzoyl Peroxide。
- **输出措辞**：本指南列为孕期“可以考虑”的外用痤疮治疗；说明共识程度与证据来源；不得声称绝对安全。
- **停止条件**：严重/结节囊肿性痤疮、系统症状、处方联合治疗、已使用系统性异维A酸或用户要求剂量建议。
